  <h1>🔍 Task 7: Identify and Remove Suspicious Browser Extensions</h1>

  <p>
    <strong>Objective 🎯:</strong>
    Learn how to spot, review, and remove potentially harmful or unnecessary browser extensions to improve security and performance.
  </p>

  <p>
    <strong>Tools 🧰:</strong> Any modern web browser (e.g., Google Chrome, Mozilla Firefox)
  </p>

  <p>
    <strong>Outcome ✅:</strong>
    Improved awareness of browser security risks and hands-on practice in managing browser extensions safely.
  </p>

  <hr />

  <h2>1️⃣ Prerequisites</h2>
  <ul>
    <li>A computer with an internet browser installed (Chrome or Firefox).</li>
    <li>Basic familiarity with navigating browser settings.</li>
    <li>Internet connection (for checking reviews and researching extensions).</li>
  </ul>

  <hr />

  <h2>2️⃣ Step-by-Step Execution</h2>

  <h3>2.1 Open the Extensions / Add-ons Manager 🧩</h3>
  <ul>
    <li><strong>Google Chrome</strong>:
      <ol>
        <li>Open Chrome.</li>
        <li>Click the three vertical dots (⋮) in the top-right corner.</li>
        <li>Go to <strong>Extensions &gt; Manage extensions</strong>, or type <code>chrome://extensions</code> in the address bar and press Enter.</li>
      </ol>
    </li>
    <li><strong>Mozilla Firefox</strong>:
      <ol>
        <li>Open Firefox.</li>
        <li>Click the three horizontal lines (☰) in the top-right corner.</li>
        <li>Select <strong>Add-ons and themes</strong> &gt; <strong>Extensions</strong>, or type <code>about:addons</code> in the address bar and press Enter.</li>
      </ol>
    </li>
  </ul>

  <h3>2.2 Review All Installed Extensions Carefully 👀</h3>
  <p>Go through the list of installed extensions/add-ons one by one and for each extension, note:</p>
  <ul>
    <li>Extension name</li>
    <li>Publisher/Developer</li>
    <li>Short description</li>
    <li>Whether you actually use it regularly or not</li>
  </ul>

  <h3>2.3 Check Permissions and Reviews 🔐⭐</h3>
  <p>For each extension:</p>
  <ul>
    <li>Click on the extension details/options link.</li>
    <li>Check <strong>permissions</strong> it asks for, such as:
      <ul>
        <li>“Read and change all your data on all websites” ⚠️</li>
        <li>“Access your browsing history” ⚠️</li>
        <li>“Manage your downloads”</li>
      </ul>
    </li>
    <li>Search the extension name on the web or the browser’s extension store and:
      <ul>
        <li>Check user ratings and reviews.</li>
        <li>Look for any reports of it being malicious or collecting data.</li>
      </ul>
    </li>
  </ul>

  <h3>2.4 Identify Unused or Suspicious Extensions 🕵️‍♂️</h3>
  <p>Mark an extension as <strong>Suspicious</strong> or <strong>Unnecessary</strong> if:</p>
  <ul>
    <li>You don’t remember installing it.</li>
    <li>It has very few users or poor ratings.</li>
    <li>It asks for excessive permissions compared to what it needs.</li>
    <li>Its name or developer looks fake, random, or misleading.</li>
    <li>Your browser has become slow or shows unwanted ads/pop-ups after installing it.</li>
  </ul>

  <h3>2.5 Remove Suspicious or Unnecessary Extensions 🧹</h3>
  <ul>
    <li><strong>In Chrome</strong>:
      <ol>
        <li>Go to <code>chrome://extensions</code>.</li>
        <li>Find the extension.</li>
        <li>Click <strong>Remove</strong> and confirm.</li>
      </ol>
    </li>
    <li><strong>In Firefox</strong>:
      <ol>
        <li>Go to <code>about:addons</code> &gt; <strong>Extensions</strong>.</li>
        <li>Click the three dots next to the extension.</li>
        <li>Select <strong>Remove</strong> and confirm.</li>
      </ol>
    </li>
  </ul>

  <h3>2.6 Restart Browser and Observe Performance 🚀</h3>
  <ul>
    <li>Close all browser windows completely.</li>
    <li>Open the browser again.</li>
    <li>Check if:
      <ul>
        <li>Pages load faster.</li>
        <li>Pop-ups or strange ads have reduced.</li>
        <li>CPU/RAM usage feels lower (system more responsive).</li>
      </ul>
    </li>
  </ul>

  <hr />

  <h2>3️⃣ How Malicious Extensions Can Harm Users 🛡️⚠️</h2>
  <p>Malicious or poorly designed extensions can:</p>
  <ul>
    <li>Steal login credentials by reading data on webpages.</li>
    <li>Track browsing history and sell data to third parties.</li>
    <li>Inject ads, pop-ups, or redirect you to phishing websites.</li>
    <li>Download additional malware or unwanted software.</li>
    <li>Hijack search engines or change browser settings without permission.</li>
  </ul>
  <p><strong>Key takeaway:</strong> Only install extensions from trusted sources and review permissions carefully. 👌</p>
